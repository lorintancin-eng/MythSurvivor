# 16 风险 / 技术债登记簿

> 状态：`[骨架 + 已知项]`
> 用于集中追踪项目层面的风险与技术债，独立于 GitHub Issue

---

## 1. 登记规则

每个风险一项，包含：
- ID（R001 起编号）
- 标题
- 类别（技术 / 设计 / 流程 / 外部）
- 严重度（高 / 中 / 低）
- 状态（识别 / 应对中 / 已缓解 / 已关闭）
- 应对策略
- 责任人
- 创建日期 / 关闭日期

## 2. 严重度判定

| 严重度 | 标准 |
|---|---|
| 🔴 高 | 影响发布 / 玩家可见 / 数据丢失 |
| 🟡 中 | 影响开发效率 / 部分功能受限 |
| 🟢 低 | 改进项 / 长期债务 |

## 6. 与 GitHub Issue 的关系

两者可互相引用（如 `参见 GitHub Issue #123`）。
