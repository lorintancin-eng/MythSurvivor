# 07 美术风格指南

> 状态：`[骨架]` — 待 Phase 2 从 core_gameplay_v_02.md §14 + V0_3 §1.3 整合

## 1. 总体风格

**暗黑志怪 + 中国水墨 + 朱砂青铜 + 程序粒子**。

不走明亮可爱国风，不走二次元卡通，不走商业 RPG 写实。走的是：阴冷、压迫、镇妖、修行、古卷。

## 4. 剪影规范

- **不画具体五官** —— 玩家与敌人都是剪影
- **标志符号识别** —— 孙悟空头戴金色单线圆环；杨戬第三眼一道金线；哪吒青莲底光
- **武器剪影简化** —— 不雕花，只保留轮廓 + 颜色

## 5. 特效规范

> 详见 [04_SKILL_DESIGN.md](04_SKILL_DESIGN.md) §6

- 优先 Godot `GPUParticles2D` 程序粒子
- 不依赖高精度贴图
- 颜色编码统一

## 6. 资源命名

> 详见 [CODE_STYLE.md](CODE_STYLE.md) "命名"

## 7. 原创性强约束

- ❌ 不抄《黑神话》《阴阳师》《王者荣耀》《吸血鬼幸存者》的视觉表达
- ❌ 不复制商业游戏的 UI 配色、字体
- ✅ 视觉灵感可来自公共领域（古画、文献插画、神话典籍木刻）

## 8. 临时占位资源

- 占位资源必须明确标注 `placeholder`
