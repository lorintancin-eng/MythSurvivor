## 1. 设计目标

### 1.1 vs 当前 v0.3 实施

| 维度 | v0.3 当前实施 | v2 新设计 |
|---|---|---|
| 主武器结构 | 3 件并列武器 | **1 主武器 + 5 个技能** |
| 主武器机制 | 旋转持续生效 | **3 段连击**（横扫→回旋扫→重棍砸地） |
| 升级深度 | 每武器 2-6 个强化 | **每技能 4 级线性成长**，Lv4 是质变进化 |
| 七十二变 | 固定无敌+移速 | **随机变化** 5 种形态 |
| 技能种类 | 无独立技能概念 | **6 大单元**（含位移/控制/标记/召唤/变化） |
| 角色定位 | 偏群战清怪 | **全能战士**（输出/位移/控制/标记/召唤/变身） |

### 1.2 设计哲学（来自用户）

1. **金箍棒是主轴**：清怪、击退、范围压制核心
2. **明确 4 级 Roguelite 成长感**：Lv4 是觉醒/进化质变
3. **技能间联动**：每个技能与其他技能有明确联动设计（见 §8.3）
4. **题材深度融合**：火眼金睛 / 筋斗云 / 七十二变 / 定身术 — 西游记孙悟空标志性能力
5. **每局体验不同**（七十二变随机形态符合 Roguelite 变化感）

## 3. 核心武器：如意金箍棒

### 3.1 定位
主武器 / 近战范围输出 / 连段清怪

### 3.2 攻击模式
**3 段连击**：横扫 → 回旋扫 → 重棍砸地

### 3.3 等级成长

| 等级 | 效果 |
|---|---|
| **Lv.1** | 自动挥舞金箍棒，对**前方扇形**敌人造成伤害 |
| **Lv.2** | 攻击范围提升，第二段攻击变为**半圆回旋扫** |
| **Lv.3** | 每第三次攻击触发**「重棍砸地」**，造成范围伤害和击退 |
| **Lv.4** | 进化为**「定海重棍」**，重击范围扩大，并留下**短暂地裂伤害** |

### 3.4 终极效果
从普通近战武器，成长为具备清怪、击退、范围压制能力的核心输出武器。

## 4. 技能一：毫毛分身

### 4.1 定位
召唤 / 协同攻击 / 清场辅助

### 4.2 设计要点
> 毫毛分身不只是召唤物，而是孙悟空的"**第二输出系统**"。前期帮忙清怪，后期可配合金箍棒和火眼金睛打爆发。

### 4.3 等级成长

| 等级 | 效果 |
|---|---|
| **Lv.1** | 召唤 **2 个分身**，自动攻击附近敌人，**持续 6 秒** |
| **Lv.2** | 分身数量 **+1**（3 只），持续时间提升至 **8 秒** |
| **Lv.3** | 分身**继承部分金箍棒攻击效果**，可触发小范围棍击 |
| **Lv.4** | 进化为**「万千猴影」**，分身消失时**爆裂**，对周围敌人造成范围伤害 |

---

## 5. 技能二：筋斗云

### 5.1 定位
位移 / 保命 / 穿怪输出

### 5.2 设计要点
> 筋斗云是孙悟空的核心生存技能。不应该只是跑得快，而是兼具**逃生、穿怪、拉扯、反打**作用。

### 5.3 等级成长

| 等级 | 效果 |
|---|---|
| **Lv.1** | 向移动方向冲刺一段距离，对**路径敌人**造成伤害 |
| **Lv.2** | 冲刺距离提升，路径留下**云雾**使敌人**减速** |
| **Lv.3** | 冲刺期间**短暂无敌**，命中敌人可**缩短少量冷却** |
| **Lv.4** | 进化为**「一念十万八千里」**，可**储存 2 次冲刺**，路径留下**金色残影伤害** |

---

## 6. 技能三：火眼金睛

### 6.1 定位
标记 / 增伤 / 破防 / 打 BOSS

### 6.2 设计要点
> 火眼金睛是孙悟空的**增伤核心**。清小怪时靠标记爆裂，打 BOSS 时靠破防和破妖印。

### 6.3 等级成长

| 等级 | 效果 |
|---|---|
| **Lv.1** | **标记**周围敌人，被标记敌人受到伤害提升 |
| **Lv.2** | 标记范围提升，被标记敌人**死亡时产生小范围爆裂** |
| **Lv.3** | 被标记敌人**受到暴击概率提升**，精英怪额外**降低防御** |
| **Lv.4** | 进化为**「照破三界」**，短时间**全屏标记**敌人，BOSS 额外叠加**「破妖印」** |

---

## 7. 技能四：七十二变

### 7.1 定位
随机强化 / 形态变化 / 局内变化感

### 7.2 设计要点
> 七十二变是孙悟空的"**随机成长技能**"，让每局体验不同，符合 Roguelite 的变化感。

### 7.3 等级成长

| 等级 | 效果 |
|---|---|
| **Lv.1** | **随机**触发一种变化形态，获得短暂强化 |
| **Lv.2** | 变化持续时间提升，**触发间隔缩短** |
| **Lv.3** | 变化期间额外获得**攻击力 / 移动速度 / 护盾**加成 |
| **Lv.4** | 进化为**「法天象地」**，触发时化为**巨猿法相**，金箍棒攻击范围大幅提升 |

### 7.4 五种随机形态

| 形态 | 效果 |
|---|---|
| **巨猿形态** | 攻击范围提升，击退增强 |
| **金雕形态** | 移动速度提升，攻击附带羽刃 |
| **石猴形态** | 获得护盾，减少受到伤害 |
| **龙影形态** | 攻击有概率释放**雷电链** |
| **灵狐形态** | **闪避**提升，留下**迷惑残影** |

## 8. 技能五：定身术

### 8.1 定位
控制 / 聚怪 / 保命 / 打断

### 8.2 技能描述
孙悟空念动法咒，释放一道**金色符印**，使范围内敌人被定在原地。基础控制时间为 **1 秒**。

### 8.3 等级成长

| 等级 | 效果 |
|---|---|
| **Lv.1** | 定住周围小范围敌人 **1 秒**，敌人无法移动但仍可受到伤害 |
| **Lv.2** | 定身范围提升，控制时间提升至 **1.3 秒** |
| **Lv.3** | 被定身敌人受到孙悟空伤害**提升**，定身结束时受到一次**符印爆裂伤害** |
| **Lv.4** | 进化为**「天罡定妖咒」**，范围大幅提升，控制时间提升至 **1.8 秒**，可短暂**打断精英怪行动** |

### 8.4 对不同敌人的效果

| 敌人类型 | 控制效果 |
|---|---|
| 普通小怪 | 完全定身 |
| 高速怪 | 完全定身，并**打断冲刺** |
| 远程怪 | 停止移动，但**仍可能保留已释放弹道** |
| 精英怪 | 控制时间**减半**，可打断部分技能 |
| BOSS | **不完全定身**，只叠加**「定妖印」**，短暂降低移动速度和攻击频率 |

### 8.5 与其他技能的联动（这是 v2 设计的关键亮点）

| 搭配技能 | 联动效果 |
|---|---|
| **金箍棒** | 定住敌人后，更容易吃满**重棍砸地伤害** |
| **毫毛分身** | 分身**优先攻击被定身的敌人** |
| **火眼金睛** | 被标记**且**被定身的敌人受到**额外伤害** |
| **筋斗云** | 冲刺穿过被定身敌人时，**额外触发残影伤害** |
| **七十二变** | 法天象地状态下释放定身术，**范围提升** |

## 11. 开放问题（待用户回答后才能实施）

### Q1. 🔴 七十二变如何触发？

v0.3 当前：灵气满 30 自动触发。v2 设计说"随机触发"但未说明条件：
- **A**：**冷却型** — 每 30 秒自动触发一次
- **B**：**条件型** — 击杀 X 个敌人后触发
- **C**：**保留灵气系统** — 沿用 v0.3 的灵气满触发（最小改动）
- **D**：**纯随机** — 每秒有 X% 概率触发

### Q2. 🔴 金箍棒连段触发机制？

横扫 → 回旋扫 → 重棍砸地 是：
- **A**：**循环式** — 每次冷却结束按序释放 1/2/3 段（第 1 次横扫，第 2 次回旋扫，第 3 次重棍）
- **B**：**连续式** — 一次冷却释放完整 3 段连击
- **C**：**条件式** — Lv1 只横扫；Lv2 自动接回旋；Lv3 第三段触发重棍

### Q3. 🔴 技能"释放"机制？

MythSurvivor 是自动战斗游戏（玩家不主动按技能）。新增技能怎么释放：
- **筋斗云冲刺**：自动按冷却？还是条件触发（如敌人贴脸自动）？
- **定身术**：周期释放？还是条件触发（如玩家受伤后）？
- **火眼金睛**：持续被动？还是周期切换？

### Q4. 🟡 每个技能怎么"获得"？

- **A**：开局只有金箍棒，5 个技能在升级池中**解锁**（类似 v0.2 飞剑/雷电）
- **B**：开局全部解锁，升级只是 Lv1→Lv4 **提升**
- **C**：开局有金箍棒 + 1-2 个基础技能，其他要解锁

### Q5. 🟡 七十二变的"随机形态"机制？

- **A**：每次触发**完全随机**（5 选 1 均等概率）
- **B**：玩家在升级时**选定 1-2 个形态**作为常态
- **C**：Lv1 只有 1 个固定形态，每升 1 级解锁 1 个新形态，Lv4 全部 5 形态可用

### Q6. 🟡 火眼金睛的"标记"是被动还是主动？

- **A**：**持续被动** — 玩家附近敌人始终被标记
- **B**：**周期切换** — 每 X 秒在周围标记 N 个敌人
- **C**：**配合其他技能触发** — 比如金箍棒命中即标记

### Q7. 🟡 升级池条目数量是否可接受？

v2 设计：6 单元 × 3 次升级（Lv1→Lv4）= 18 个孙悟空专属升级条目 + 4 通用 = 22 条目。

vs 当前 v0.3 修行者约 25 条目。**升级池规模可比**，但密度更集中。

- **A**：18 条目 OK
- **B**：减到 12 条目（每单元 2 级合并）
- **C**：增到 24 条目（每单元 4 级独立强化）
