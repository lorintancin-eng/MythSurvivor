# 11 通用验收清单标准

> 状态：`[骨架 + 通用框架]` — Phase 2 时将 v0.2 QA 清单提炼通用模板
> 配套模板：[templates/QA_CHECKLIST_TEMPLATE.md](templates/QA_CHECKLIST_TEMPLATE.md)

---

## 1. 验收的两层结构

```
通用验收清单（本文档）— 适用于所有任务 / 所有版本
   ↓
版本/任务专属清单 — 基于通用清单 + 当前改动定制
   ↓
QA 实例记录 — 实际执行某次 QA 的结果（如 QA_V0_2_RESULTS.md）
```

## 2. 通用 DoD（Definition of Done）

任何任务通过验收必须满足：

### 2.1 代码层
- [ ] 实现完成（feature-worker 报告 done）
- [ ] reviewer 审查通过（无阻塞问题）
- [ ] 在授权文件范围内（无越界修改）
- [ ] 无新增红色脚本错误 / 解析错误
- [ ] 无场景引用断裂

### 2.2 功能层
- [ ] 主流程可手测通过（按任务专属清单）
- [ ] 不破坏既有功能（关键回归项通过）
- [ ] 性能无明显退化

### 2.3 文档层
- [ ] 涉及架构变更已更新 [ARCHITECTURE.md](ARCHITECTURE.md)
- [ ] 涉及配置变更已记录
- [ ] 涉及重大决策已创建 ADR（见 [decisions/](decisions/)）

### 2.4 工作流层
- [ ] qa-tester 已输出手测清单
- [ ] 在 [10_TASK_BACKLOG.md](10_TASK_BACKLOG.md) 中状态已更新
- [ ] 用户已明确授权 commit / push（如适用）

## 3. 通用 Smoke Test（每次 commit 前必跑）

最小集合，1 分钟内完成：

- [ ] Godot 编辑器打开项目无错误
- [ ] 主场景按 F5 可启动
- [ ] 玩家可移动、攻击
- [ ] 击杀至少 1 个敌人，敌人正常死亡
- [ ] 拾取至少 1 个修为，HUD 正常更新
- [ ] Output 面板无红色 push_error

## 4. 通用回归项（按变更范围选择）

| 改动类型 | 必须回归 |
|---|---|
| 玩家系统 | 移动、攻击、受伤、死亡、Restart |
| 敌人系统 | 生成、追击、死亡、XP 掉落、精英、Boss |
| 武器系统 | 自动触发、命中、伤害、冷却、所有已解锁武器 |
| 经验/升级 | 拾取、升级面板弹出、选择后恢复、效果应用 |
| 关卡系统 | 计时、阶段事件、镇妖碑、Boss 触发、通关 |
| UI 系统 | HUD 显示、文案、面板互斥、按钮响应 |

## 5. 版本级验收标准

### 5.1 通用版本发布门禁

任何版本发布必须满足：

- [ ] 所有该版本任务状态为 ✅ 完成
- [ ] 通用 DoD 全部通过
- [ ] 该版本专属手测清单全部通过
- [ ] 控制台无红色错误
- [ ] [09_ROADMAP.md](09_ROADMAP.md) 已更新该版本状态
- [ ] release notes 已撰写（基于 [templates/RELEASE_NOTES_TEMPLATE.md](templates/RELEASE_NOTES_TEMPLATE.md)）
- [ ] 用户已明确授权打 tag + 发布
- [ ] git 工作区无未跟踪的不相干文件

### 5.2 版本专属清单

每个版本应有自己的 QA 清单：

| 版本 | QA 清单 | 状态 |
|---|---|---|
| v0.2 | [archive/v0.2/QA_V0_2_CHECKLIST.md](archive/v0.2/QA_V0_2_CHECKLIST.md) | 已编写，未执行 |
| v0.3 | （待 v0.3 开发完成时由 qa-tester 输出）| ⏳ |

## 6. 失败判定通用标准

满足任一即为 FAIL，需要回炉：

- 控制台出现红色 push_error
- 玩家无法移动 / 攻击 / 死亡
- 场景引用断裂导致节点加载失败
- 关键 UI 不显示或显示错位
- 帧率明显下降（< 30 FPS 在合理负载下）
- 数据丢失（如修为 / 等级 / 升级效果未应用）
