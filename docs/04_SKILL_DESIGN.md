# 04 技能 / 武器 / 特效设计

> 状态：`[骨架]` — 待 Phase 3 从 V0_3_CHARACTERS.md §5 + v0.2 现有武器脚本反向梳理

---

## 1. 设计原则

- 每个角色 2-3 件标志武器，不堆叠
- 武器有 6 项强化路径（伤害、范围、冷却、数量、行为变种、终极进化）
- 不同武器的攻击模式（目标 / 范围 / 触发方式）必须有区别
- 数值原创，通过本地试玩调校

## 2. 武器分类

### 2.1 按攻击模式

| 类型 | 描述 | v0.2 示例 |
|---|---|---|
| 追踪投射 | 自动锁定最近敌人 | 追魂符 |
| 方向投射 | 朝玩家朝向射出 | 飞剑 / 金箍棒·变长 |
| 范围爆发 | 一次性 AOE | 雷电符咒 / 山河印 |
| 持续区域 | 在某区域内持续生效 | 八卦阵 |
| 命中爆发 | 命中后产生次级效果 | 爆裂符 |
| 召唤 | 独立 AI 单位 | 毫毛分身 / 哮天犬 |
| 蓄力 / 大招 | 高冷却高伤 | 开天斧 / 开辟 |

### 2.2 按流派

| 流派 | 特征 |
|---|---|
| 符法系 | 追踪、爆裂、封印、减速 |
| 剑修系 | 直线、穿透、回旋 |
| 雷法系 | 范围爆发、多目标、连锁 |
| 阵法系 | 近身防御、持续伤害 |
| 法宝系 | 大范围、高冷却、特殊机制 |

## 3. 武器基类规范

> [Phase 3 与 weapon_base.gd 对齐]

### 3.1 共享字段
- `damage: float`
- `cooldown: float`
- `range: float`
- `element: String`  # 五行属性，v0.4+ 启用
- `character_owner: String`  # 角色归属，用于升级池过滤

### 3.2 共享方法
- `_can_fire() -> bool`
- `_fire()`
- `_apply_upgrade(upgrade_id: String)`

## 6. 特效设计规范

> 详见 [07_VISUAL_STYLE_GUIDE.md](07_VISUAL_STYLE_GUIDE.md)

- 优先用 Godot 程序粒子，避免依赖高精度贴图
- 颜色编码：金色（输出）/ 青色（治愈/水）/ 红色（火/爆裂）/ 紫色（控制）/ 银白（雷电）
- 每个武器有独特"识别色"，玩家一眼能区分

## 7. 数值平衡基线

> [Phase 3 数值整理]

- 单角色满构筑期望 DPS：~600（修行者）/ ~700（孙悟空）
- 单武器贡献占比：最强武器不超过 40%
