# 08 UI / UX 指南

> 状态：`[骨架]` — 待 Phase 2 从 core_gameplay_v_02.md §6 术语包 + scripts/ui/*.gd 反推

---

## 1. UI 设计原则

- 暗黑志怪风（旧纸黄 + 朱砂红 + 黛黑）
- 信息密度低，关键信息突出
- 不遮挡核心操作区域
- 字体古风但可读

## 5. 升级面板规范

> [Phase 3 与 LevelUpPanel.tscn 对齐]

- 三张卡片左中右排列
- 每张卡片：技能图标 / 名称 / 简要描述 / 效果数值
- 鼠标 hover 高亮，键盘 1/2/3 选择
- 选择后面板消失，恢复游戏

## 6. HUD 状态机

> [Phase 3 补全 UI 状态切换]

```
开始 → InGame → (Boss 预警时叠加横幅) → (升级时弹面板) → Boss出现 → 击败 → 封印完成 / 道消身陨 → 再入劫境
```

## 8. 视觉与可读性

- 关键数字（气血、修为）必须用大字号
- 颜色不仅传达信息，配字 / 形状辅助色弱玩家
- 高频更新的标签用事件驱动，不每帧重绘
