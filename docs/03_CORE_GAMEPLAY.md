## 1. 游戏定位

中国神话暗黑志怪风的闯关式 Roguelite 生存游戏。玩家进入山海劫境，在 5 分钟妖潮试炼中修行悟道、封印镇妖碑、解锁符法与法宝，最终迎战妖王。

## 2. 核心设计原则

1. 每关目标明确（5 分钟 + Boss）
2. 技能通过升级逐步解锁
3. 暗黑志怪风格优先
4. 地图必须有目标点（镇妖碑）
5. 构筑要有流派感

## 3. 单关流程

```
进入关卡
   ↓
0:00-1:00  入劫       基础敌人 + 第一波修为
1:00-2:00  妖潮增强   速度型/群体型怪物
2:00-3:00  镇妖碑显现 引导玩家离开安全区
3:00-4:30  精英压迫   精英怪 + 组合
4:30-5:00  妖王预警   屏幕提示妖气暴涨
5:00 后    妖王降临   Boss 出现，击败后通关
```

## 4. 玩家行为契约

| 行为 | 手动 / 自动 |
|---|---|
| 移动 / 躲避 | 手动 |
| 攻击 / 释放技能 | 自动（按冷却 + 目标规则） |
| 拾取修为 | 自动（进入范围） |
| 升级选择 | 手动（暂停三选一） |

## 8. 镇妖碑机制

> 详见 [06_LEVEL_DESIGN.md](06_LEVEL_DESIGN.md) §4

每局 2:00 左右生成 1 个镇妖碑。玩家进入范围封印 8 秒，完成后获奖励，封印期间有风险事件。
